# 05 · 英雄品级专属武器与商业化攻击特效管线方案（对标《永远的蔚蓝星球》）

> 工程：`code_2`（《宋江别慌张》）  
> 对标基准：《永远的蔚蓝星球》正式服品级视觉阶梯（稀有【游侠】→ 史诗【蘑菇头/骑士/火法】→ 传说/绝世【火箭/暴风/河掌柜/闪电之子/赵云/剑仙】）  
> 核心目标：**告别多英雄共用同一根木箭/黑炸弹/绿风片、告别长枪截断像短棍与光条糊住枪头；实现全 32 位好汉「一人一器、品级三阶分明、商业化 `FxUber` 动态流场特效」**

## 一、现状痛点复盘与《永远的蔚蓝星球》核心美术体验法则

### 1.1 我们之前的四大表现硬伤
1. **跨品级共用同款投射物，传说毫无尊贵感**：
   - 稀有猎户**解珍**、史诗神射**花荣**、传说浪子**燕青**三人射出的竟是同一支普通红白羽木箭 `fx_arrow` + 同款蓝白风套；
   - 稀有**孔亮**、史诗**凌振**、史诗**魏定国**三人扔出的全是同一个黑铁圆球 `ic_bomb`；
   - 稀有**孙二娘**（蒙汗药）、稀有**阮小七**（渔网）、史诗**朱武**（八阵图）、传说**樊瑞**（旋风咒）飞行或命中全都走同一张硬编码薄荷绿 `fx_wave`！
2. **长柄兵器贴图截断失真，渲染被纯色光条糊死（「林冲的枪根本不像枪」）**：
   - 旧 `wp_snakespear` 枪杆截得极短像根黑木杵，`wp_spear`（麒麟枪）甚至只截了枪尖三撮红毛没画枪杆；
   - `BattleView.ShotView` 在长枪上叠了一张半透明蓝三角盖住枪头，身后又拉了一条纯色扁蓝带 `_lance`，并把传说**林冲**、传说**卢俊义**、史诗**徐宁**做成一模一样的白线受击，既看不出枪形，也没有品级差距。
3. **武器与角色立绘脱节**：
   - **秦明**立绘肩扛烈火狼牙棒，出手却只飞一团发飘的半透明火球；**关胜**立绘手握盘金青龙翠刃大刀，飞出去却是半截灰铁片；**石秀**立绘拿宋制圆盘护手快刀，飞出去却是西洋短剑；**朱武**立绘手执蓝旗，出手却飞绿风。
4. **首页出征演示（`AttackStage`）受击简化**：
   - 主界面好汉演示打中台阶怪物时只闪一个白点 `Flash`，未能同步展现好汉品级命中特效。

### 1.2 对标《永远的蔚蓝星球》的三阶商业化视觉铁律
拆解《蔚蓝星球》从蓝卡【游侠】到橙/红/粉卡【火箭、赵云、暴风、剑仙】的战斗美术管线，其核心体验建立在三条铁律之上：

| 品级阶梯 | 对标案例 | 武器本体设计准则 | 飞行弹道管线（`ShotView`） | 出手与命中反馈（`Muzzle` & `PlayHit`） |
|---|---|---|---|---|
| **稀有（蓝）**<br>`Rarity = 2` | 游侠（猎箭）<br>地鼠 / 冰法 | **朴实硬朗、材质纯粹**：生铁、硬木、麻绳、粗陶，轮廓一眼识物，不堆金饰与发光纹 | **单层清爽物理破风**：干净主体 + 单道轻盈半透风丝尾迹，不挂厚重能量球，保证前期棋盘清爽 | **干脆点状物理反馈**：利落切线 + 3~4 颗铁花/木屑/药粉轻雾，不震屏、不铺大光斑 |
| **史诗（紫）**<br>`Rarity = 3` | 蘑菇头（毒箭）<br>骑士（旋风斧）<br>火焰法师 | **精良军制、元素鲜明**：寒银、赤铜、雕翎、符瓮、八卦旗，带专属色彩标识 | **双层元素气场包裹**：主体置顶清晰 + 专属元素破风锥/旋流环 + 双股丝缕拖尾 | **中等范围元素绽放**：`ArcSlash` 单层弧光 / 元素气浪环 + 贴地焦痕/油海/阵盘残留 |
| **传说（橙）**<br>`Rarity = 4` | 火箭（连弩弹幕）<br>赵云（苍龙逐月枪）<br>暴风（风刃龙卷） | **神兵气象、鎏金瑞兽**：鎏金吞口（豹首/麒麟/青龙）、燕尾金翼、烈焰狼牙，与立绘神兵 1:1 呼应 | **商业级 `FxUber` 多层动态流场**：下层深色衬底防亮砖发灰 + 中层双通道噪波滚动流焰/盘龙枪罡 + 高亮核心置顶神兵 + 粒子星尘伴飞 | **名场面级复合爆点**：双层异色 `ArcSlash` 刀枪裂罡 + `FxUber` 噪波侵蚀冲击波 + 16 帧序列帧天雷/爆破 + 实体冰晶/金羽碎片迸射 + 微顿震屏 |

## 二、全 32 位好汉专属武器与品级特效逐一落地方案

### 2.1 射手系（4 人：解珍 蓝 → 解宝 蓝 → 花荣 紫 → 燕青 橙）
- **解珍（稀有·两头蛇）`wp_arrow_hunt`**：山林寒铁三角猎箭（深棕硬木杆 + 灰褐鹰羽）。飞行仅挂轻巧素白细风丝；命中爆小簇铁花与插地猎箭。
- **解宝（稀有·双尾蝎）`wp_fork`**：淬毒三股倒钩钢叉。飞行裹幽绿毒雾尖锥 + 碧绿毒丝尾；命中迸发蝎毒绿芒与毒液飞溅，插地残留钢叉本体（修复原插地变木箭 Bug）。
- **花荣（史诗·小李广）`wp_arrow_cloud`**：白翎穿云银箭（修长寒银双翼箭镞 + 翠玉金箍 + 雪白长雕翎）。飞行挂 `FxUber` 翠青银白螺旋破云激波 + 双股白羽流光；每次穿透爆开翠青音爆环与十字寒星，终末拉出整条银青裂空贯通箭痕。
- **燕青（传说·浪子）`wp_bolt_yanqing`**：鎏金燕翎机巧弩矢（三棱破甲金锋 + 青蓝镶金燕尾翼片 + 琥珀流火尾芯）。出手弩机金芒连闪；三连发裹挟 **`FxUber` 赤金流火破空激波 + 鎏金残影尾带**；每矢命中绽开**十字鎏金破甲微弧斩 + 四芒金星 + 飞溅金羽火星**！

### 2.2 长柄突刺系（3 人：徐宁 紫 → 林冲 橙 / 卢俊义 橙）
- **废除糊住枪头的旧蓝块**：所有长柄神兵采用 `3:4` 修长全尺寸立绘，渲染排序**神兵本体置顶（9212）**，流场枪罡衬于枪颈与枪身两侧，寒光枪尖与红缨分毫毕现！
- **徐宁（史诗·金枪手）`wp_hookspear`**：全长金甲雁翎钩镰枪（主枪锋旁探出醒目弯月倒钩镰刃）。突刺带金青锐利破风气锥；命中划出弯月金钩割裂弧光与碎甲铁花。
- **林冲（传说·豹子头）`wp_snakespear`**：全长寒星银豹红缨丈八蛇矛（修长百炼寒钢蜿蜒蛇矛尖 + 银豹吞口 + 烈红长缨 + 乌木银箍长杆）。突刺对标《蔚蓝星球》赵云「苍龙逐月」：**`FxUber` 双层寒霜苍龙螺旋枪芒**沿枪身翻涌向前，枪尖寒星闪耀、枪尾飘散风雪冰晶；命中拉出**霜龙裂空贯阵长痕 + 交叉冰青斩芒 + 冰晶钢片齐飞**！
- **卢俊义（传说·玉麒麟）`wp_spear`**：全长鎏金玉麒麟红缨枪（阔叶寒银枪尖带麒麟金翼 + 黄金麒麟吞口 + 朱红描金长杆）。突刺裹挟 **`FxUber` 煌金赤焰麒麟破阵枪罡**；命中轰出**黄金裂地贯通枪波 + 左右双道鎏金 `ArcSlash` 挑阵气刃 + 漫天金星迸射**！

### 2.3 近战劈砸/挥砍系（5 人：石秀 蓝 → 武松 紫 / 李逵 紫 / 鲁智深 紫 → 关胜 橙）
- **石秀（稀有·拼命三郎）`wp_fast_sabre`**：寒钢圆盘护手拼命快刀（匹配立绘，替换西洋短剑）。稀有级去重型风球，改为利落银白高速旋刃残影 + 寒铁切线，轻快凌厉。
- **武松（史诗·行者）`wp_ironfist`**：黑铁镶金虎贲重拳。飞行裹 **`FxUber` 琥珀烈金音爆拳罡**；命中补齐**刚猛金橙崩山气浪环 + 重拳冲击弧光 + 碎石地裂**（修复原版只有灰土无拳罡的问题）。
- **李逵（史诗·黑旋风）`wp_axe`**：沉重双刃精铁板斧。保留并提纯对标《蔚蓝星球》骑士的**深海苍青旋风刀环 + 风壳丝缕**，命中劈开青白旋斩弧与斜插板斧。
- **鲁智深（史诗·花和尚）`wp_staff`**：重绘全长浑铁金环水磨月牙禅杖。腾空旋转裹**罗汉琥珀佛金罡风**，砸地迸发暖金震地波与龟裂碎石。
- **关胜（传说·大刀）`wp_broadsword`**：重绘全长盘金青龙吞口翠玉偃月刀（100% 对齐立绘）。空中劈落拖出 **`FxUber` 翡翠青龙流焰刀罡弧带 + 双重青金残影**；落地轰出**传说级双层巨幅青龙偃月斩（翠碧外焰 + 鎏金龙脊）+ 翡翠裂地波 + 冲天青金刀芒**！

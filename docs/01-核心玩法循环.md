# 对上了 · 核心玩法循环

> **体验北极星**（更高优先级）：见 [00-体验目标.md](./00-体验目标.md)  
> 主体验 = **我对上了这两个字。**  
> 本文所有循环与规则都是实现该体验的手段；新增或改动前先过体验目标的「设计审视清单」。

---

## 1. 核心循环

```
一句写死的通知落到纸上 → 字池摊开 → 点两个字（顺序算数）
        ↑                                      ↓
  下一句 / 下一局          对上：那句话被改写
                           顺序反了：提示换过来
                           组错 / 踩坑：扣一次机会
```

单局自闭环。局外首版只记「改过的句数」，不做第二条养成线。

**「点两个字」是独立的一步，不自动配对。**  
系统可以提示「这两个能对」，但不能替玩家对上。省掉这一步，游戏就退回「点一下消词」。

## 2. 一句话，不是一条路

场上只有三种东西：那句话、字池、你已经对上的词。

| 为什么这样 | 说明 |
|---|---|
| 那句话是局面，不是基地 | 玩家改的是语义，不是守一个点。没有路，怪就不会「漏」 |
| 字是单位 | 每个字一张牌，认得出、点得着。不超过 12 个 |
| 词是一次行动的结果 | 两个字对上才成为词。单字待在池里，什么都不做 |
| 不需要棋盘 | 棋盘会把玩家拖去想站位，那是 srpg 的活 |

**语序是这条循环的全部策略厚度。**  
「请 + 假」是请假，「假 + 请」是组错。没有第三条隐藏规则。玩家学的就是：对着那句话，想哪两个字、哪个在前。

## 3. 失败条件：对不上，不是没守住

**没有底线血量，没有漏怪，没有路线。**

- 组错次数用尽（含顺序反了、踩到让局面更糟的词）→ 判负
- 本句超时还没对上 → 判负
- 本局每一句通知都被改写 → 通关

位置、移动、抵达不产生任何胜负。回归测试必须钉死：状态机里不存在 `lane` / `leak` / `baseHp`。

## 4. 词对：主体验的载体

每一次行动都是一对有序字 `(a, b)`。结果只有四类：

| 结果 | 含义 | 玩家应感到 |
|---|---|---|
| `rewrite` | 对上了，那句话变成另一句 | 「我对上了」 |
| `reversed` | 这两个字能成词，顺序反了 | 「换过来」 |
| `trap` | 也是词，但让局面更糟 | 「这对不能用」 |
| `miss` | 对不上 | 「不是这两个」 |

每条 `rewrite` 必须能回答一句：**它让那句话从什么变成了什么。**  
只加分、不改句子的词一律不做。

切片词库的典型对：

| 对 | 结果 | 那句话变成 |
|---|---|---|
| 取 + 消 | rewrite | 「今晚全体加班」→「今晚全体取消」 |
| 消 + 取 | reversed | 句子不变，提示换顺序 |
| 摸 + 鱼 | rewrite | 「今晚全体加班」→「今晚全体摸鱼」 |
| 请 + 假 | rewrite | 「今晚全体加班」→「今晚你请假」 |
| 加 + 班 | trap | 句子更冲，扣一次机会 |

两条硬约束：

- **一局里，同一对成功词只算一次。** 对上就从池里拿掉这两个字，逼下一句换词。
- **每句至少两条 rewrite、一条 trap、一条能验语序的 reversed。** 只有一条解，聪明感会退化成猜谜。

## 5. 通知是靶子，不是关卡列表

每一句通知提供一个主题和一批字。通知换了，字池换了，能对上的词换了。  
通知不是「第 3 关」，没有星级、没有战力、没有推荐阵容。

首版主题走现代职场：加班、方案、明天继续。大众都认识，审核稳，直玩素材好拍。

## 6. 单局节奏

| 段 | 内容 | 意图 |
|---|---|---|
| 第 1 句 | 解法直白（取消 / 请假 / 摸鱼），陷阱是「加班」 | 十秒内打出第一次「对上」 |
| 第 2 句 | 解法仍清楚，开始罚语序 | 建立「换过来」 |
| 第 3 句 | 字池里同时放能赢的词和陷阱词 | 验取舍，不是验手速 |

切片做成一整天 8 句，大约 3–5 分钟。第一句手把手教「取 + 消」，后面才加字。

组错机会：全局限 4 次。太少会变成小心翼翼不敢点；太多会让「对」不再值钱。

## 7. 可读性

主快感是看见一句话被自己改歪。**看不懂那次对上，就等于没做。**

| 信息 | 表现 | 为什么排这个优先级 |
|---|---|---|
| **对上看得见** | 两个字撞成词，通知正文立刻换成新句 | 主体验第三个可检验点 |
| 语序反了 | 两个字晃一下，提示「顺序反了」 | 卡关路径必须指向换序，不是重开 |
| 踩坑 | 陷阱词盖到句子上，句子更冲 | 让「这对不能用」比扣命更先被看见 |
| 还剩几次 | 纸面上三枚印，砸错一枚就糊掉 | 失败来自对不上，不要做成血条 |
| 本句还剩多久 | 细线，不做成倒计时炸弹 UI | 超时是失败条件之一，但不能抢「对上」的戏 |
| 结算 | 列出本局对上的词，一句「靠这几对」 | 体验验收第一条 |

明确不做：全屏技能、棋盘格、沿路小兵、合并升级闪光、连击倍率。

## 8. 十秒开场

| 时间 | 画面 |
|---|---|
| 0.0s | 直接在纸面上。通知已写着「今晚全体加班」 |
| 0.6s | 字池弹上，中央一句「点两个字，顺序要对」 |
| 2.0s | 若还没点，高亮一对能对上的字，但不代点 |
| 第一次对上 | 通知换句，提示淡出。主体验完成一次 |

验收：录前 10 秒给没玩过的人看。说不出「点两个字改那句话」，就要改开场；若他说塔防 / 合成 / 消消，回去查第 3 节和第 4 节。

## 9. 广告位

核心流程只放 2 个。

| 广告位 | 位置 | 核心流程 |
|---|---|---|
| 结算奖励双倍 | 局末，展示双倍后的具体进度 | 是 |
| 组错续一条命，或本句加时 | 第三次组错 / 超时的当下，续上才能保住这句已经改过的半成品 | 是 |
| 每日首局多给一对明牌 | 进局前 | 否，局外 |
| 每日换一套主题纸面 | 主界面 | 否，局外 |

续命卖的是「保住这句已经改到一半的话」，不是「重开一局」。  
切片阶段广告位只留接口与按钮位置，不接真实 SDK。

## 10. 埋点事件表

| 事件 | 关键字段 | 用途 |
|---|---|---|
| `run_start` | seed, theme | 局数 |
| `run_end` | cleared, duration_ms, words, misses, reverses | 体验验收、卡关分布 |
| `pair_try` | a, b, result, notice_id | **验证取舍与语序** |
| `notice_rewrite` | notice_id, word, from, to | 主体验是否发生 |
| `ad_show` / `ad_close` | placement, completed | 中位数 IPU |

必看：

1. 中位数 IPU ≥ 6，同时看「开战 ≥20 场的人里 IPU < 2 的占比」
2. `pair_try` 里 `reversed` 之后下一次是否出现同一对的正确顺序 —— 学没学会「对」
3. `notice_rewrite` 的词分布 —— 某一对超过 70%，说明这句没有真取舍
4. 结算页停留时是否发生过「再看一眼对上的词」—— 归因有没有被看见

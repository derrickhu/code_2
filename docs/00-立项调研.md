# 立项调研：水浒 ×《永远的蔚蓝星球》玩法，纯 IAA（2026-10）

> 工程：`code_2`　暂名：《守住梁山》　平台：微信、抖音小游戏，团结引擎 `2022.3.62t8` 同一工程分别转换　变现：首版纯 IAA

---

## 一、结论

**能做，但它是一次没有先例的押注，要按「小步测款、按回收率止损」来立项。**

- **玩法被验证过，变现方式没有。** 《永远的蔚蓝星球》和唯一的古风同类《城主别慌张》都是靠内购抽卡赚钱。10 月 29 日微信畅玩榜（广告变现游戏的榜）前 100 里，没有一款这种「城墙前召唤英雄、合成升星、三选一强化」的纯广告产品。可以理解为空位，也可以理解为纯广告撑不起这套养成，两种可能都在，只能靠测款回答。
- **必须和 `code_3`《营救宋江》拉开。** 两款都是水浒加随机召唤合成塔防。本作用 Q 版人物、单人守寨墙、局内词条构筑、局外广告抽卡养成；`code_3` 用汉字、1V1 对称、组字召唤、局外只给外观。具体对照见第四节。
- **合理预期：** 做成日收入几千元的中腰部产品就算合格。塔防用户买量贵（抖音塔防类广告变现游戏的关键行为出价约 160～170 元，益智类约 10～15 元），广告收入回本慢于消除。

## 二、对标：《永远的蔚蓝星球》到底靠什么

### 2.1 成绩

| 项 | 数据 | 来源 |
|---|---|---|
| 研发 / 发行 | 广州颂悦（诗悦网络体系），9377 参与发行 | 公开报道 |
| 上线 | App 2025-05 底，微信小游戏 2025-07 | 公开报道 |
| App 首月 | iOS 畅销最高第 7，首月流水预估超 2 亿 | 腾讯新闻 2026-07 |
| 投放 | 2026 年 5 月一个月投 224 条素材；穿山甲 31%、优量汇 15%、QQ 音乐 14% | 游戏研究所 pro |
| 代言 | 周杰伦，官宣 16 天后首次登微信畅销第 1；后又加李雪琴、徐志胜 | 同上 |
| 现状（10-29） | 微信畅销第 15、抖音畅销第 22、华为畅销第 4；买量总榜第 18；**不在畅玩榜** | 同上 |

### 2.2 局内（我们要借的部分）

来自官网新手引导、TapTap 攻略和网易的玩法拆解：

| 机制 | 规则 |
|---|---|
| 布局 | 竖屏，怪物从上往下压，英雄站在底部城墙上；城墙血量归零即失败 |
| 召唤 | 开局 100 银币；花银币召唤随机英雄（来自上阵的 4 人），杀怪掉银币；每次召唤涨价 |
| 格子 | 初始 7 格，每召唤 5 次加 1 格，最多 12 格；满格只能合成腾位 |
| 合成 | 两个同种同星英雄合成，**结果随机成为上阵 4 人中的任意一个**的高一星；最高 4 星（4 星约为 1 星的 4 倍伤害）；合成出的英雄立刻放一次技能 |
| 强化 | 另一个按钮，花银币三选一词条；词条涨价比召唤快，因为词条作用于全体同名英雄 |
| 词条路线 | 每个英雄 2 条以上的局内构筑路线（如暴风的风刃流 / 旋风流）；大招词条权重高，大招约 20～30 秒一次，伤害约普攻 5 倍 |
| 波次 | 10 波，约 3 分钟一局；小怪从约 12 只涨到约 100 只，血量只涨约 1 倍——**数量涨、血量不怎么涨**，所以构筑成型后能一下清一片 |
| Boss 节奏 | 第 4 波出 Boss，第 7 波走到城墙，要在 7～8 波前打死；前松、中紧、后松 |
| 克制 | 7 职业（射手、法师、战士为主输出，毒、辅助、控制、召唤为辅）；怪物分普通、肉盾、高速、飞行、远程，并对某些职业减伤；关卡给某职业加成，玩家看加成选人 |
| 保底 | 主线中第一个 3 星若不是主输出，第二个 3 星必定是主输出 |

**核心体验：** 召唤随机和词条随机同时随到最好时，两者相乘的爆发。网易拆解原话是「不要老想着填平负面体验，没有低谷就没有峰值」。

### 2.3 局外（它真正赚钱的部分，我们拿不到）

- 升级制卡池、抽卡保底、英雄碎片升到 30 级、专武、图腾洗练、披风洗练、城墙皮肤。
- 主线有数值卡点，卡住了就去付费；高品质装备只从合作模式掉，合作模式要先付费推主线才能解锁。
- 玩家口碑集中在「逼氪、锁卡池、暗改、难度断崖」。

**对我们的含义：** 纯广告变现只能把抽卡改成「看广告拿招募令」，付费深度会掉一大截。这套局外靠广告能撑多久，是本项目最大的未知数。

### 2.4 古风同类：《城主别慌张》

- 名臣健康（广州星炫 / 冠游）发行，2026-05-04 上微信畅销榜，最高进前三，长期在前 15。
- 局内比《永远的蔚蓝星球》简单：5 人上阵、20 波、升级三选一、怒气大招、守城计策（召唤弓兵、滚石）。
- 局外：Q 版国风女性门客卡牌、阵营羁绊、官职晋升、城镇经营（林场、铁匠铺、包子铺），后期接 SLG。
- 变现：内购为主，夹带广告。高峰日投素材 850～1200 条。母公司上半年因推广投入过大，预计亏损 600～900 万。

**对我们的含义：** 古风题材放在这个框架里是成立的，但对手是上市公司砸量的打法，我们不跟它拼内购深度和买量规模。

## 三、为什么还值得试

1. **玩法本身足够上头。** 3 分钟一局、三重随机、Boss 节奏一松一紧，这套已经由两个畅销榜头部产品验证过。
2. **纯广告变现这边目前是空的。** 畅玩榜上的塔防是《赵云与阿斗》（文字 1V1）、《守了个桥》、《冰火防线》、《小兵防卫战》等，没有这种召唤合成加词条的形态。
3. **水浒是免费的大 IP，而且天然适合这个框架。** 108 将正好对应收集；好汉绰号直接就是技能（霹雳火、神行太保、浪里白条）；「守梁山、打官军」天然是守城叙事。
4. **团队条件匹配。** `black-rosa` 已经做过竖屏塔防射击、城墙血量、体力、结算、广告位，团结双端出包也跑通了。

## 四、和 `code_3`《营救宋江》的区隔

| 维度 | `code_3`《营救宋江》 | 本作《守住梁山》 |
|---|---|---|
| 对标 | 《赵云与阿斗》 | 《永远的蔚蓝星球》 |
| 画面 | 汉字 + 水墨，字变兵器 | Q 版好汉人物 + 技能特效 |
| 对局 | 上下对称 1V1，护宋江 | 单人守寨墙，官军从上往下压 |
| 召唤结果 | 刀枪弓骑字牌 + 好汉单字 | 直接召出好汉（来自上阵 4 人） |
| 核心决策 | 拼名字、同姓抢字、摆位置 | 留主输出还是合掉、召唤还是买词条 |
| 局内构筑 | 道具（2 主动 + 6 被动） | 好汉专属词条路线、大招 |
| 局外 | 好汉谱只给外观；兵器、座次 | 广告抽卡收集好汉、升星升级、按关卡克制选阵 |
| 目标用户 | 刷到《赵云与阿斗》的泛休闲用户 | 玩过靶心类塔防（向僵尸开炮、蔚蓝星球）、愿意养成的轻中度用户 |

**两个项目共用：** 好汉设定表（姓名、绰号、兵器、名场面）、原著关卡事件、审核口径（第八节）。**不共用：** 美术、玩法代码、素材。

## 五、立项点：《守住梁山》（暂名）

### 5.1 一句话

> 高太尉的官军要踏平梁山。你站在寨墙上点「聚义」，下一个跳上墙的是谁？两个李逵一合，合出来的可能是武松。

### 5.2 局内（照抄骨架，只改三处）

**骨架照抄 2.2：** 竖屏、寨墙血量、上阵 4 名好汉、召唤随机、7 格起每 5 次召唤加 1 格最多 12 格、同种同星两两随机合成最高 4 星、合成即放技能、另一个按钮三选一词条、10 波 3 分钟、第 4 波出 Boss、怪物数量递增而血量缓增。

**只改三处：**

1. **名场面词条。** 每个好汉的终极词条是原著名场面，选到时全屏演出 1 秒：武松「醉打」（连续 18 拳）、林冲「风雪山神庙」（一列冰封）、花荣「射雁」（必杀飞行单位）、鲁智深「倒拔垂杨柳」（拔起一棵树横扫一路）。这是素材的主要卖点。
2. **兄弟同场。** 上阵 4 人里有原著关系就带被动加成：阮氏三雄同时在场时水路伤害加倍，林冲和鲁智深同场时近战加成。作用和《永远的蔚蓝星球》的「冰火交锋」词条一样，换成玩家都懂的关系。
3. **克星演出。** 每章 Boss 有原著克星（祝家庄的栾廷玉对孙立、连环马对徐宁的钩镰枪），克星在场伤害大幅提高并有专属演出。这对应《永远的蔚蓝星球》的职业克制，但读起来不用查表。

### 5.3 职业与好汉

职业沿用 7 类思路，首发压到 5 类，减少美术和数值量：

| 职业 | 首发好汉 |
|---|---|
| 步战（近战主输出） | 武松、鲁智深、李逵 |
| 马军（突进、击退） | 林冲、秦明、呼延灼 |
| 弓弩（远程主输出） | 花荣、庞万春（P2）、张清（飞石） |
| 法术（范围） | 公孙胜、樊瑞 |
| 军师 / 辅助 | 吴用（全队攻速）、戴宗（减速敌人）、时迁（偷敌方增益） |

首发 12 人，P2 扩到 36 天罡，P3 起 72 地煞分批上。

### 5.4 局外（用广告替代内购）

| 系统 | 做法 | 广告关联 |
|---|---|---|
| 招募 | 招募令抽好汉；**招募令只来自通关、每日任务和看广告**，不能充值 | 每天限次看广告领招募令 |
| 保底 | 10 抽必出稀有好汉，概率公示 | — |
| 好汉升级 | 重复卡转碎片升星；金币升级 | 结算双倍 |
| 寨墙 | 寨墙血量、自动反击（对应《永远的蔚蓝星球》的城墙机关） | — |
| 聚义厅座次 | 通关数换座次称号，排行榜 | 分享 |
| 每日军令 | 每日一关固定阵容挑战 | 失败可看广告重来一次 |

**原则：** 卡点放在主线第 3 章之后（参考《永远的蔚蓝星球》前 7～8 小时几乎不卡）；不让「不看广告打不过」出现在前 3 章。

### 5.5 广告位

| 位置 | 内容 | 类型 |
|---|---|---|
| 结算 | 双倍金币 / 碎片 | 核心 |
| 招募 | 看广告领招募令 | 核心 |
| 局内 | 寨墙破时「援军到」：回复一半寨墙血量，每局 1 次 | 功能 |
| 局内 | 三选一不满意时刷新一次 | 功能 |
| 开局 | 看广告开局送一个 2 星好汉 | 功能 |
| 体力 | 补体力 | 功能 |

**目标：** 人均每日广告观看次数 ≥ 8（参考同类重养成纯广告产品，三国塔防《你过来呀》每人每天约 20 次）。局内战斗中不弹非玩家主动触发的广告。

### 5.6 美术与技术

- **美术是本作最大的成本**，远重于 `code_3` 的汉字方案。首发 12 名好汉 × 4 星形态（换色和配件区分星级，不重画）、5 类官军、5 个 Boss、12 个名场面演出。用 `game-art-pipeline` 走 AI 出图、切图、去背景，统一 Q 版风格。
- 同屏单位最多约 100 只：怪物、子弹、伤害数字全部对象池；战斗逻辑集中在一个纯 C# 模拟层里批量更新。
- 复用 `black-rosa`：城墙血量、波次刷怪、结算、体力、广告封装、云开发排行榜。

**测款止损线：** 次留 < 30%，或人均每日广告次数 < 5，或首日回收率 < 0.10、7 日回收率 < 0.25（腾讯 60 天回本口径），任一项不达标就停，不硬扛。

## 七、风险

1. **纯广告撑不起养成**：这是最大的风险，也是空位存在的可能原因。测款时重点看 7 日留存和人均广告次数，不只看次留。
2. **美术量**：Q 版人物加技能特效，产能远高于 `code_3`。首发严格压在 12 人，靠 AI 管线出图。
3. **和 `code_3` 抢量**：用户群体有交叉。两款错开上线；素材分别主打「汉字拼名」和「Q 版好汉合成」。
4. **随机性口碑**：《永远的蔚蓝星球》被骂「暗改」。我们保留保底（第一个 3 星若不是主输出，第二个必是），并公示招募概率。
5. **审核**：好汉打官军有「反官府」解读风险。敌人以原著具名反派（高俅部将、祝家庄、曾头市）和「贪官恶霸爪牙」为主，不出现「朝廷」「皇帝」字样；不做招安、征方腊；无血腥表现。
6. **投放能力**：选对品只是入场券。如果自己投，前两次测款大概率亏学费；预算紧就优先谈发行代理。
7. **预期过高**：按公开案例，做成日收入几千元的中腰部产品就算合格，不要按「对标周杰伦代言产品」来定预算和人力。

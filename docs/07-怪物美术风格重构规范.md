## 一、重构背景与旧版痛点

1. **颜色过深发闷**：旧版官兵大面积使用深藏青、暗炭灰、深棕皮具与重黑阴影，在手机 76px 成群涌来时糊成一团深灰黑块，缺乏商业休闲塔防的通透爽感。
2. **细节过碎成噪点**：鱼鳞甲片、皮带扣、铆钉、刀鞘挂件、复杂虎头盾纹在小尺寸下全部变成杂色噪点，显得廉价且脏。
3. **俯视辨识度弱**：头顶轮廓雷同，缺少大块头盔/盾牌/坐骑色块，割草时看不清混在怪群里的特殊机制兵种。

## 二、新风格核心铁律（对标《永远的蔚蓝星球》软萌小怪）

### 1. 比例与体块（2 头身圆润软胶感）
- **小怪（Minion）**：**1.8～2.0 头身**，圆滚滚豆子身材，手脚简化为圆润短肢。**加大头盔/帽饰占比（占身高约 45%～50%）**，确保 3/4 俯视战场一眼看清兵种。
- **精英（Elite）**：**2.2 头身**，体型更敦实宽厚，带一件醒目的亮色披风、大旗或异色重甲壳，和普通小兵一眼拉开体量。
- **首领（Boss）**：靠 **大型Q版载具 / 萌凶坐骑 / 巨型器械** 拉开层级（战鼓车、猛虎、铁头撞车、楼船等），车体与坐骑同样遵循圆润大色块、无碎木纹与碎甲片原则。

### 2. 严禁碎细节（三不画原则）
- **不画鱼鳞甲与方格纹**：所有铠甲一律合并为**整片光滑圆润的亮色甲壳**（如冰银圆胸甲、珍珠白圆锅盔）。
- **不画碎皮带扣与挂件**：取消腰包、副武器刀鞘、铆钉、绑腿绳、衣服褶皱暗部杂线。
- **不画写实脏迹与复杂纹章**：盾牌只用**同心圆环、大月牙、单颗圆星**等极简几何图形；面部只用粗弯眉、豆豆眼/半眯凶萌眼与腮红点缀。

### 3. 明亮高调阵营色板（大宋官军统一视觉）
为了在暖米色石板地（`battle_bg`）上清亮跳脱，同时与我方梁山好汉的红橙金暖色主调形成清晰敌我区分，官军采用 **「珍珠白 + 矢车菊蓝紫 + 蜜柑朱红点缀」** 的高明度色板：

| 色板角色 | 色值参考 | 用途 |
|---|---|---|
| **珍珠亮白 / 冰银** | `#F4F7FC` / `#DCE5F5` | 官兵圆锅盔、铁甲兵整片圆甲壳、刀枪亮面 |
| **矢车菊蓝紫（官服主色）** | `#7A89FE` / `#5C6CE8` | 官兵战袄、盾兵兜帽、骑兵衣袍 |
| **蜜柑朱红（敌军警示点缀）** | `#FF6A4D` / `#FF8552` | 头顶毛球红缨、盾牌外圈、火药引信与骑兵头盔 |
| **暖阳明黄（金属/盾面辅色）** | `#FFD15C` | 帽徽圆章、盾牌内环、刀柄护手 |
| **暖深褐描边** | `#2B2338`（不用纯死黑） | 粗细均匀的外轮廓描边，内部线条极简 |

## 三、全兵种视觉识别单点设计（35 种怪物）

每个兵种只靠 **1 个超大几何特征** 让玩家在 0.2 秒内认出机制：

### A. 核心官军步骑（第 1 批）
1. **官兵（`en_soldier`）**：超大珍珠白圆盔 + 橙红大绒球 + 蓝紫短袄 + 双手举一把厚实短宽刀。
2. **盾兵（`en_shield`）**：蓝紫圆兜帽 + 身体前举一面**占满身宽的橙黄同心圆大盾**（只露眼睛和小短腿）+ 短矛。
3. **骑兵（`en_cavalry`）**：橙红圆盔小兵骑在**圆滚滚的白棕小矮马**上，持短骑枪前冲。
4. **弩手（`en_crossbow`）**：橙红软帽 + 浅米白短衣，端一把粗萌橙木小弩。
5. **铁甲兵（`en_armored`）**：全身包裹在**光滑冰银色圆桶盔甲**里（只露窄缝里两只眼睛），头顶大红缨，扛大白圆锤（一眼看出高物抗）。
6. **火药兵（`en_firebomb`）**：扎橙红头巾，怀里抱一颗**比肚子还大的紫黑色光滑圆炸弹**，头顶亮黄大火花。

### B. 章节特色小怪（第 2 批）
- **藤牌手（`en_rattan`）**：暖鹅黄编织圆斗笠 + 浅绿圆藤盾（画一圈极简白纹）。
- **敢死刀手（`en_berserker`）**：火红爆炸头带 + 赤膊小麦肤色圆肚皮 + 双手亮银大砍刀。
- **斥候（`en_scout`）**：蓝紫色圆忍者兜帽蒙面 + 飘起一条亮青长围巾 + 小短匕。
- **水鬼（`en_diver`）**：湖水青绿圆脑袋顶一片大荷叶 + 水汪汪蓝皮肤 + 短鱼叉。
- **庄客（`en_farmer`）**：暖金大草帽 + 浅蓝布衣 + 扛一把三齿圆头木耙。
- **恶犬（`en_hound`）**：圆滚滚焦糖棕小恶犬 + 亮黄圆钉项圈。
- **鹰隼（`en_hawk`）**：蓝白配色圆胖小猛禽，大黄喙，展开圆润双翼。
- **妖道（`en_taoist`）**：亮紫高道冠 + 浅薰衣草紫宽袍 + 手拿洁白大拂尘。
- **力士（`en_brute`）**：超大号粉橙圆肚壮汉，背着光滑亮黄大竹篓，篓口探出两颗小白圆盔脑袋。
- **投石车（`en_catapult`）**：暖黄圆木小推车，勺里托一颗光滑大灰圆石。
- **孔明灯（`en_lantern`）**：暖橘发光大圆纸灯笼，底下吊一颗小紫圆炸弹。
- **生辰纲（`en_porter`）**：头戴橙帽的圆胖脚夫，扁担挑两个亮金红绸大宝箱。

### C. 9 大精英与 10 大首领（第 3～4 批）
- **精英统一升级语言**：体型大一圈，配 **亮金边角 + 鲜明披风/背部大旗**，保持光滑大色块无碎鳞片。
- **首领统一升级语言**：人小车/兽大（圆胖萌虎、亮红金大鼓车、朱红小官船、圆头铁撞车），色彩鲜亮饱满，与小怪同属一个玩具世界观。

## 四、制作与接入管线约定

1. **生成模型**：统一使用 Vertex `gemini-3-pro-image`，每次传入 `sample_d_chubby_minion.png` 作为画风锚定参考图（`--image`），确保全军画风、描边粗细、色温 100% 统一。
2. **序列帧规格**：
   - 有帧动画的兵种生成 `1×4` 横条（帧0 标准站立、帧1 微蹲呼吸、帧2 蓄力后仰、帧3 挥砍出手），纯白底 `#FFFFFF`。
   - 经 `python3 code_2/tools/anim_frames.py` 自动去白底、对齐脚底中线，输出 `Assets/Resources/Art/<name>.png`（首包立绘）与 `Assets/ArtCdn/<name>_0..3.png`（战斗帧），并增量更新 `AnimMeta.cs`。
3. **旧走路帧处理**：替换新画风 `_0..3.png` 时，同步移出旧版深色画风的 `_walk_0..7.png`（备份至 `game_assets`），避免走路时闪回旧画风；无 `_walk` 帧时引擎自动启用 `Bend` 软萌迈步形变，后续可按需用 `game-anim-pipeline` 补齐新版走路视频帧。

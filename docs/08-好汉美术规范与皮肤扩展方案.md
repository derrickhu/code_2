## 二、面向「皮肤 & 4星满星觉醒」的模块化素体架构

为确保后续低成本、高还原度量产 **4 星合体觉醒形象** 与 **商业化主题皮肤（神话皮、节庆潮玩皮、机甲皮）**，全员设计严格遵循 **「1 套灵魂骨相 + 3 个可换装槽」**：

1. **不可变灵魂锚点（跨皮肤 100% 锁死）**：
   - **标准素体与朝向**：统一 `2.2` 头身潮玩素体，全员标准 **`3/4` 朝右下（面向镜头偏右）** 站姿，保证局内 `2★/3★` 不翻转整齐列队且换皮零位移。
   - **角色辨识度铁三角**：专属脸型眉眼/胡须 + 标志发型轮廓（如林冲高髻短须、武松狂放高马尾、鲁智深光头虬髯、扈三娘高马尾女将）+ 本命武器大类剪影。
2. **三大皮肤可变槽（换皮只改这三处）**：
   - **槽位 1 · 冠冕头饰**：例 林冲 `银豹发冠` → 4星觉醒 `冰晶苍龙角冠` → 神话皮 `黑金修罗冠` → 贺岁皮 `醒狮萌头冠`。
   - **槽位 2 · 战袍胸甲与披风（≤3 块大色块）**：整片光滑护甲或劲装色块替换材质与主题色，不改身体胖瘦与脚底站位。
   - **槽位 3 · 本命神兵外观**：保持握持手势与动作轨迹一致，升级武器形态（寒铁枪 → 冰晶龙枪 → 熔岩火矛 → 祥云彩球枪），可无缝联动专属弹道皮肤 `wp_<hero>_<skin>`。
3. **资源命名与管线预留规范**：
   - 默认原皮：`Resources/Art/hero_<id>.png` + `ArtCdn/hero_<id>_0..3.png`
   - 4 星满星觉醒态：`hero_<id>_s4`（`SlotView.Sync` 检测到 `u.Star >= 4` 且存在 `_s4` 贴图时直接切换觉醒立绘与帧包）
   - 商业皮肤：`hero_<id>_skin_<key>`（如 `hero_linchong_skin_shura`，在 `SaveData` 记录当前穿戴皮肤键，未穿戴回退默认 `Art`）

## 四、4帧动作条与切帧接入标准

1. **生成输入**：使用 Vertex `gemini-3-pro-image` / `gemini-3.1-flash-image` / `gemini-nano-banana-2.1`，统一传入横排 `1×4` 锚定图 `style_a_1x4_ref.png`（`16:9`），强制单行横排四帧（`0 待机站立` / `1 呼吸微蹲` / `2 蓄力起手` / `3 挥击释放`），武器全程握在手中，严禁画出脱手飞出的箭矢或刀光残片。
2. **画布分辨率与体型标尺校准**：
   - **战斗 4 帧（`Assets/ArtCdn/hero_<id>_0..3.png`）**：统一输出 `512×512` 方形帧画布；`tools/anim_frames.py` 通过 `HERO_HUMAN_H` 按「真实鞋底 → 标准头顶冠线（不含高举长枪、大旗、长翎）」写入 `AnimMeta.Info[name].Body`（常规角色统一落于 `0.64` 占高，超长枪/高旗角色由 `BattleView`、`HomeScreen`、`RankUi`、`MetaRecruitUi` 按 `1 / Body` 自动等比还原），彻底杜绝长柄武器角色被压矮、无冠角色被放大的体型参差。
   - **首包立绘（`Assets/Resources/Art/hero_<id>.png`）**：统一输出到 `380×390` 紧凑标准透明立绘画布（靴底锚定 `y = 384`，人体标准头顶高度固定 `342px`，垂直占高 `87.7%`），消除头顶空隙并确保结算碎片框、卡牌网格、战斗 HUD、排行榜头像与弹窗中所有 `Ui.Icon` 渲染时全员全身完整入框、大小与脚底基线 100% 对齐。

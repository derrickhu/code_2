# 对上了 · 垂直切片范围

> 本文只回答：这一刀切什么、不切什么、怎样才算切到。  
> 体验对错仍以 [00-体验目标.md](./00-体验目标.md) 为准。  
> 好切片标准对齐 code_1：穿过玩法、表现、闭环、变现、数据；薄在不做大厅/养成，不薄在「广告以后再说」。

---

## 1. 这一刀要验的一句话

没玩过的人打完这一局，能指着结算说：**「靠取消 / 摸鱼 / 请假这种词，把通知改了。而且上午组的词，下午那句就不一样。」**

验不到这句话，切片失败。

## 2. 切进去的层

| 层 | 切到什么 | 本刀标准 |
|---|---|---|
| 规则 | 8 句职场一天、有序组对、四类结果、4 次组错、单句限时 | 纯逻辑可单测，状态机无 lane / leak / baseHp |
| 单局闭环 | 进纸面 → 对上 → 结算点名靠哪几对 → 再来 | 能赢能输能重开 |
| L3 案底 | 上午对上的词最多换掉后面 2 句，画面写「因为你组了××」 | 不问「下一句为什么不同」答得出来 |
| 十秒开场 | 0 秒就看见通知和字；第一句手把手取+消 | 无菜单、无选关 |
| 语义演出 | 两个字撞成词，新通知砸下来，印章「改」 | 色块 + 系统字 + 短振 |
| 语序教学 | 反序给出「顺序反了」，正序才能改句 | 消取 必须可复现 |
| 商业闭环 | 组错/超时续一次；结算记双倍 | 无 adUnitId 时 mock 700ms 视为成功 |
| 验收数据 | run_start / pair_try / notice_rewrite / ad_* / run_end | console + 本地环 |
| 局外弱进度 | 最高改写句数、上局的词 | 本地即可，不要养成 |

## 3. 这一刀明确不切

| 层 | 为什么现在不切 |
|---|---|
| 抖音包 / 真实 adUnitId | 微信包已按 code_1 runtime 接上。填广告位是上线前的事 |
| 24 句工厂 / 第二主题 | 会稀释「对上」验收 |
| L2 新语法 / L4 模式 | 03 排在案底之后 |
| 立绘、棋盘、音效全集 | 字就是美术；振感先顶手感 |
| 大厅、图鉴、词稀有度 | 会抢走「对上」 |

## 4. 切片内容（锁死）

主题：职场一天，8 句通知。第一句带手把手引导。

| 句 | 通知 | 要改掉的词 | 能对上的词 |
|---|---|---|---|
| 1 | 今晚全体加班 | 加班 | 取消 / 摸鱼 |
| 2 | 周会改到晚上 | 晚上 | 提前 / 取消 |
| 3 | 方案被毙了 | 毙了 | 能成 / 重来 |
| 4 | 客户说再改一版 | 再改 | 过了 / 定稿 |
| 5 | 午饭缩短十分钟 | 缩短 | 加长 / 取消 |
| 6 | 谁还没交点名 | 点名 | 已交 / 请假 |
| 7 | 明天继续 | 继续 | 放假 / 鸽了 |
| 8 | 全公司通宵 | 通宵 | 取消 / 放假 |

全局限 4 次组错。第一句 40 秒，其余约 32 秒。对上进入下一句。
界面必须让人看见：要改哪两个字、先/后槽、改完的新通知。

## 5. 怎样才算切到（验收）

1. 问「刚才怎么赢的」，答案里有具体两个字。
2. 至少能主动把一对反序纠正为正序。
3. 前 10 秒盲测：不会被说成塔防、合成、自走、消消。
4. 组过「取消」之后，下一句必须能看见「因为你组了取消」。
5. 组错或超时会弹出续命，不直接死；结算能点记双倍。
6. `npm run build` 通过（类型 + 测试 + 产物）。

## 6. 计划（做完再给看）

1. 写下 00 / 01 / 02 / 03。
2. `PairEngine` + 8 句词库 + 最多 2 次案底，测试钉死四类结果、续命、禁区字段。
3. 微信包：纸面、字池、演出、案底、续命/双倍、结算、再来。
4. 用微信开发者工具打开 `build/wechat/` 体验。能对上、能看见因为、能续一次就停。

# 对上了 · 体验目标（设计北极星）

> **本文件优先于一切玩法、数值、系统、商业化文档。**  
> 后续任何设计、改需求、加系统，都必须先用本文「审视清单」过一遍；通不过则改方案或砍掉，而不是改体验目标去迁就功能。

品类：单局文字组对 · 语义构筑  
平台：微信 / 抖音小游戏　变现：首版纯 IAA；IAP 只预留结构，待版号后再开（见 §5.1）  
工作名：对上了　正式名未定，不在切片阶段起营销名

## 1. 基调

**一句话世界观**

> 通知、方案、群消息已经写死了。你手里只有散落的字。两个字对上，这句话就被你改了。

字是单位，不是装饰。玩家认的是字本身，不认立绘、不认血条、不认路线。基调服务「十秒可懂」：人看见两个字撞在一起变成词，立刻知道自己在干什么。

| 项 | 定 |
|---|---|
| 玩家位置 | 改写那句话的人。不是守门的人，不是合成升级的人，不是看戏的人 |
| 对手 | 已经写死的局面句：加班通知、被毙的方案、明天继续。句子有态度，不是一波怪 |
| 画风 | 纸、墨、大字。通知像通知，字像活的。不做立绘英雄，不做棋盘，不做路径 |
| 色系 | 纸用暖米／浅茶；字用浓墨；对上用砖橙；组错用暗朱红。不要科技蓝，不要史诗金 |
| 文案 | 短句、口语、能当梗。胜利说「对上了」，不说「战斗胜利」；组错说「顺序反了」，不说「无效操作」 |
| 音效 | 纸页、印章、两个字撞上的短促一声。对上偏脆，组错偏闷。不要刀剑、不要技能吟唱 |

**命名规则**：夸张归语义变化，文字只负责好笑和说清楚。不要奇幻词，不要技能腔，不要把词写成 Buff 名。

## 2. 主体验目标

**正式表述**

> 当熟悉汉字和梗的玩家在碎片时间开一局时，反复感到：**「这两个字对上了，局面就被我改写了」**——赢来自我把哪两个字、按什么顺序砸在一起，而不是我手速快或者肝得久。

**一句话**

> **我对上了这两个字。**

**玩家应脱口而出**

- 「拆开就是废字，对上才是人」
- 「这对也太损了」
- 「刚才那组词把局面翻了」
- 「顺序反了，换过来」

**这句话的含义要落到三个可检验的点**

1. **本局独有**：这一局对上的词，和上一局不是同一套笑话、同一套解法。变化不是数值累加，是语义被改写。
2. **对象是具体的字**：玩家能指着屏幕说「就这两个」。不是全场 buff，不是自动匹配。
3. **语义看得见**：对上之后，字、词、那句话同时变。不靠飘字「+12 攻击」说明发生了什么。

**主体验的核心动词是「对」。**  
选、点、拖都可以，但玩家心里完成的动作必须是「我对上了」，不是「我消了」「我合成了」「我守住了」。

## 3. 反目标（坚决避免）

玩家若经常感到以下任一，即体验目标失败：

| 反目标感受 | 典型诱因（设计上要挡） |
|---|---|
| **「这不就是个塔防吗」** | 失败条件写成漏怪、命条、路线、守门；字变成沿路走的兵 |
| **「这不就是合成吗」** | 两个相同单位合并升级；对子只加攻击数字，不改那句话 |
| **「这不就是自走棋吗」** | 放下去之后只剩看戏，组对不再是每一步的主操作 |
| 「这不就是文字消消吗」 | 清盘条件变成连线 / 三消 / 五连，语义不再重要 |
| 「打不过就是没抽到字」 | 稀有字黑箱决定胜负；组对策略被运气淹没 |
| 「字太多，看不懂在干什么」 | 词库无主题、无语序、没有「对上了」的瞬间 |
| 「系统太多，不知道该干啥」 | 多养成线、多货币、局外目标冲突 |

**头号风险是第一条和第二条叠在一起。**  
业界验证这条赛道的爆款（《赵云与阿斗》）本身就是「文字合成 + 守阿斗」。它证明了「汉字当单位」能打穿畅玩榜，也同时证明：壳一旦是塔防加二合，第一眼就不再是「我对上了」。我们借它的单位，不借它的壳。

**语序必须能罚。**  
「请假」和「假请」若效果相同，玩家就学不会「对」。顺序反了必须被认成一次真实的组错，并给出比「无效」更清楚的路径：换过来。

## 4. 玩法骨架（体验的实现方式）

| 层级 | 内容 | 说明 |
|---|---|---|
| **主** | 从字池里选出两个字，确认语序，组成一个有效词 | 「对上」这一步就是主体验的动作，不能省成自动匹配 |
| **强辅** | 对上之后的语义演出 | 两个字撞成词，那句话被改写，底下甩一句梗。让「对上了」看得见 |
| **弱辅** | 本局主题词库 | 职场通知、方案、群消息。给组对提供弹药，不做成图鉴收集主线 |

**硬性骨架**

| 项 | 值 | 为什么 |
|---|---|---|
| **失败条件** | 组错次数用尽，或本句超时 | 只要写成「漏怪扣血」，第一眼永远是塔防 |
| **胜利条件** | 本局主题句全部被改写 | 赢要能指回「靠哪几对词」 |
| **场上同时可见的字** | ≤ 12 个 | 认得出每一个。再多，「就这两个」指不出来 |
| **合成升级** | **不做** | 两个同类合并加攻击是花花的识别符 |
| **路线 / 底线血条** | **不做** | code_1 栽过的坑，换皮救不了 |
| **自动战斗** | **不做** | 主操作必须是组对，不是看戏 |
| **克制** | 只做一眼懂的语义相克 | 「灭」克「火」。不做属性三角，不做隐藏克制表 |

**聪明感的关键时刻**：手里两个看似废字，换个顺序突然成词，场上那句话被反转。  
若玩家卡关后第一反应是「再来一局碰字」而不是「换个组合 / 换语序」，主目标已偏。

## 5. 人群与游玩情境

以下每条都是硬约束，不是建议。来源是 2026 小游戏大盘、微信 IAA 用户结构，以及仓库里已有产品的分工。

### 5.0 人群

| 层 | 是谁 | 他们要什么 | 他们不要什么 |
|---|---|---|---|
| **核心** | 18–35 岁，城市，微信 IAA 盘里的人（该盘 70% 只玩休闲广告游戏） | 「我组对了」的聪明感，一句能转发的梗 | 转珠手操、战棋学习、肝养成 |
| **泛** | 25–40 岁轻度玩家，被直玩素材点进来 | 认得字就能玩；单局能打完；看广告换续命说得通 | 读技能说明、认英雄立绘、等匹配 |
| **不做** | 重度 IAP 养成、动作手感党、温馨经营党、看英雄打架党 | — | 已分别由 xiaochu / 跑酷筛掉 / 花花 / code_1 与 srpg 覆盖 |

**核心用户的工作，不是人口统计。**

> 我只有三到六分钟。我要做成一件事：把一句写死的话改成我想要的。做成了，我知道是哪两个字的功劳。

他们可能玩过羊了个羊、文字游戏、沙雕小游戏，未必玩过战棋或转珠。文化门槛必须低到：认得字就能玩；不认得某个梗，也不妨碍组出另一个。

**和 code_1 的人群关系**：同一批 IAA 用户，月人均在玩 7.5 款。code_1 占 7–10 分钟的战斗袋；本品类占 3–6 分钟的组对袋。可以轮着玩，不能互相替代。

### 5.1 游玩情境

| 约束 | 值 | 为什么 |
|---|---|---|
| 单局长度 | 3–6 分钟 | 碎片时间可完整打完；比 code_1 短，占不同时间袋 |
| **十秒可懂** | 前 10 秒内必须看到一次「对上 → 那句话变了」 | 直玩已是 IAA 买量第一大形态。开局不允许有选关、图鉴、编队等前置页 |
| **核心流程广告点 ≤ 2** | 只放「结算双倍」与「组错续一条命 / 加时」 | 大盘：核心单流程广告点少于 3 个时新进次留约 23%，3–5 个掉到 17%。xiaochu2 排了 4 个，正落在差的那一档 |
| **中位数 IPU ≥ 6** | 看中位数不看平均 | xiaochu2 平均 7.9 是两名重度用户抬起来的，一个活跃玩家真实值只有 0.57 |
| 不接插屏 | 切片与首版都不接 | 插屏与激励视频抢同一频控窗口，激励视频 eCPM 更高 |
| 首版无内购 | 不开 IAP，按 §5.1 预留结构 | 无版号。任何「靠付费深度才能过」的设计在无版号期只会劝退 |
| 平台 | 微信优先，抖音同步 | IAA 自然量先跑微信；抖音最优分成绑买量 |
| 场合 | 单人 | 实时 PVP 匹配会拖死十秒可懂和短回收 |
| 题材 | 现代或大众文化符号优先 | 2026 上半年现代题材在投近 7000 款，审核风险低于仙侠魔幻 |

### 5.2 IAP 预留原则

首版纯 IAA，但**结构从第一天就要留**。xiaochu2 的教训：免费经济先按「完全没有付费」校准，再塞付费，只能打折硬挤。

| 档位 | 内容 | 为什么归在这一档 |
|---|---|---|
| **现在就必须定** | ① 资源发放走同一入口，带 `source`（`free` / `ad` / `iap` / `quest`）<br>② 账本以服务端为权威，订单幂等接口形状先留<br>③ 定义「一次广告 = 多少资源」<br>④ 埋点按 `source` 分账 | 事后改等于重做存档信任与数值校准。**只做接口形状，不接支付 SDK** |
| **可以后加** | 商店 UI、SKU、定价、月卡、支付 SDK、审核资质 | 叶子功能，不动核心循环 |
| **即便开了 IAP 也不做** | 卖「必出词」或词库抽卡；直售胜率；付费墙式难度 | 对上的快感来自「我组对了」。词能买，构筑就变成付费进度条 |

**日后 IAP 优先卖字体外观、纸面皮肤、主题词库的cosmetic。** 不卖胜率。去广告要谨慎：它直接吃 IAA。

## 6. 设计审视清单（必过）

新增或改动玩法 / 数值 / UI / 商业化前，逐条回答。任一条为「否」且无法修正 → **不做或降权**。

1. **对上能改语义**：这个词是否改写了那句话的意思？（纯数值加成不算）
2. **语序有差异**：同一对字反过来，结果是否明显不同？
3. **指得出来**：场上是否仍认得出每一个字？新增演出是否把字挡住了？
4. **不像塔防**：是否引入了防线血条、漏怪、路径、阻挡数？若是，直接砍。
5. **不像合成**：是否出现了两个相同单位合并升级？若是，直接砍。
6. **卡关路径**：玩家卡住时，游戏是否把「换组合 / 换语序」提示为比「再来一局碰字」更清晰的路径？
7. **胜利归因**：结算是否让人感到「我对上了」，而不是只感到「这局运气好」？
8. **十秒可懂**：改动后，前 10 秒是否仍能让没玩过的人看到一次组对生效？
9. **广告点预算**：核心流程广告点是否仍 ≤ 2？
10. **变现不成为前置**：是否制造「不看广告就过不去」或「不付费就过不去」？涉及 IAP 时追加：这件商品若上线，是否会让不付费玩家的现有体验变差？会则不做。
11. **系统负担**：是否增加了让玩家忘记「对上」的干扰目标？

## 7. 加 / 慎 / 砍（速查）

| 倾向 | 例子 |
|---|---|
| **加** | 语序相反的真惩罚、对上后那句话立刻变、结算点明「本局靠哪几对」、主题词库轮换、组错时提示换顺序 |
| **慎加** | 局外成长、第三句以上的长叙事、实时对手、超过 12 个字的场面 |
| **砍 / 降权** | 漏怪与底线血；同类合并升级；自动战斗；转珠消字；棋盘布阵；词库抽卡与付费胜率；前置选关页；核心流程第三个广告点；插屏 |

## 8. 验收标准（体验是否达标）

| 维度 | 标准 | 测法 |
|---|---|---|
| **体验** | 玩家能说出本局是靠「哪几对词」改过来的 | 试玩后问「刚才怎么赢的」。答案指向具体两个字即通过；答「运气」或「不知道」即不通过 |
| **语序** | 玩家至少主动纠正过一次顺序 | 看是否出现「假请 → 请假」这种回头。从未纠正则语序没有被教出来 |
| **不像邻品** | 没玩过的人看完前 10 秒，不会说这是塔防、合成、自走、消消 | 录前 10 秒盲测 |
| **商业** | 中位数 IPU ≥ 6，且次留不低于改动前 | 埋点看中位数，同时看「开战 ≥20 场的人里 IPU < 2 的占比」 |
| **节奏** | 单局 3–6 分钟，卡关来自「对不上」而不是时间耗尽占八成 | 切片阶段先用 3 句通知验「对上」密度 |

最可能挂掉的是**体验**那条。它挂了就不是调时限能救的，要回到词对语义改写的强度。

## 9. 与其他工程、与其他文档的关系

本文件是本品类唯一的体验裁决依据。`docs/01-核心玩法循环.md`、`docs/02-垂直切片.md` 是实现手段；`docs/03-宏观设计.md` 管怎么长寿、哪些层能加。宏观设计不得改写本文的主体验与反目标。

**不得与仓库已有工程重叠**（按玩家第一眼的玩法识别符，不按题材）：

| 工程 | 它的识别符 | 本品类禁区 |
|---|---|---|
| code_1 | 改装件 + 自走队列 | 自走观战、三选一肉鸽、漏怪守线 |
| xiaochu2 / xiao_chu | 转珠 + 编队克制 | 转珠、属性克制 RPG |
| caizhu-rosa | 五连消除 | 连线 / 三消 / 五连 |
| hot-pot | 物理捞取 | 捞、夹、抓 |
| game2D_huahua | Merge-2 合成经营 | 二合升级、订单经营 |
| srpg-rosa | 轻战棋布阵 | 棋盘、兵种克制、关卡布阵 |

向《赵云与阿斗》只借「汉字当单位、单字没用、对上才活」。不借守门、不借二合升级、不借站桩输出。

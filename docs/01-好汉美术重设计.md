# 01 · 好汉美术优化

状态：原型阶段，尚未接入游戏。
图：`game_assets/code_2/assets/concept/opt/`（`raw/` 原图，`cut/` 抠好的单人），`concept/人物优化_对比板.jpg`（新旧对比、剪影、手机尺寸）。
提示词：`docs/prompt/hero_redesign_prompt.txt`。

## 一、方向

保留游戏现有画风：约 3 头身的日系 Q 版、干净深色描边、柔和赛璐璐上色，原姿势、原比例、原脸型都不变，只做减法和差异化。

试过两种推倒重来的方向，都已放弃：
- “国潮潮玩”（3D 软胶）：太立体，颜色和细节多。
- “2D 平涂大头”：太幼稚。

## 二、旧图的问题

1. **细节太碎**：皮带、扣子、小甲片、腰包、刺绣，手机上糊成噪点。
2. **撞色**：张清和吴用都是浅蓝；林冲和武松都是深蓝黑；凌振的棕色发闷。
3. **撞头饰**：花荣、张清、林冲、武松四个人都扎头带，头顶轮廓雷同。
4. 称号没画出来，比如豹子头、花和尚、轰天雷在外形上看不出。

## 三、优化规则

1. **去小细节**：去掉皮带扣、腰包、鳞片纹、刺绣，合并成几块大色面。
2. **一人一个主色**，全员不撞色，颜色整体提亮。
3. **头带只留给武松**（行者金箍），其他人换成各自的头顶特征。
4. **称号落在一个外形点上**，只加一处，不堆。
5. 描边略加粗。

## 五、对比结论

- 姿势和剪影基本保持原样（有意为之，保证和现有动作帧、界面布局兼容）。
- 64px 下颜色更干净，九个人各自一个色块：张清和吴用、林冲和武松不再撞色。
- **仍需留意**：凌振（红）、武松（橙）、鲁智深（红褐）同属暖红系。如果实战里分不清，可以把鲁智深的袍子改成赭黄。

# 13 - 微信广告点位方案与接入清单

## 一、商业化设计原则

《宋江别慌张》（`wxde332003e4d0ef23`）采用纯 IAA 微信小游戏变现架构，围绕「局内救急爽感 + 结算收益放大 + 局外养成加速」三层漏斗布局，遵循以下准则：

1. **高价值点做深，不设强制卡点**：局内战败复活、天降神运三张全收、强化刷新、生辰纲鸿运重转均为高意愿主动触发。
2. **零广告红点骚扰**：所有看视频免费次数均采用翠绿按钮 + 视频角标呈现，绝不在底栏或建筑上挂常驻红点逼迫点击。
3. **插屏严格克制**：仅在通关第 3 关后、未看结算激励视频返回主界面时低频触发；设启动 180 秒保护、间隔 180 秒冷却、看完激励视频后 90 秒免弹保护，每日最多 6 次。
4. **不铺常驻底部 Banner**：竖屏底部为寨墙操作区与五页签导航栏，不放置易误触且遮挡画面的横幅广告；仅预留可选悬浮单格原生模板接口。

## 二、微信公众平台（流量主）注册清单

## 三、技术接入与稳定性保障

1. **多广告位单实例现建现拆（`multiton = true`）**：每次拉起激励视频前先销毁上一个闲置实例，再按当前入口 `adUnitId` 新建 `WXRewardedVideoAd`，既保证微信分广告位独立结算统计，又避免一次性常驻 9 个实例在鸿蒙/低端机引发卡顿或二次播放无回调。
2. **全屏广告静音保护**：`Sfx.SetAdMute` 在激励视频或插屏展示瞬间静音游戏 BGM 与音效，关闭后平滑恢复，杜绝广告与背景乐叠音。
3. **前台回归兜底（`WX.OnShow`）**：若极端机型关闭广告回到前台后宿主漏发 `OnClose`，延时检测自动解封状态并发放回调，防止遮罩锁死。
4. **平滑回退与全链路埋点**：未填写 `adUnitId` 或处于编辑器/自检环境时，自动走 2 秒内置演示层；`Analytics` 同步上报 `ad_request`、`ad_show`、`ad_close`、`ad_error`，携带真实 `ad_unit_id`、`ad_type` 与 18 个细分 `scene`。

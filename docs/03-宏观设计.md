# 对上了 · 宏观设计（开发总纲）

> **体验裁决仍以 [00-体验目标.md](./00-体验目标.md) 为准。**  
> 本文回答三件事：这个游戏靠什么长寿、哪些层可以加、哪些层永远不加。  
> 后续开系统、开主题、开模式，先过本文 §8 再过 00 的审视清单。通不过就砍，不改体验目标去迁就功能。

工作名：对上了  
品类：单局文字组对 · 语义构筑  
平台：微信 / 抖音小游戏　变现：首版纯 IAA

---

## 0. 先承认：只堆通知，会无聊

现在的切片是「一天 8 句职场通知」。它能验「对上了」这一下，**不能当成品**。

若后面的开发等于「再写 80 句加班 / 取消 / 请假」，玩家会在第二局感到：

- 我又在猜两个字
- 句子换了，手还是那一下
- 赢了也不想发给别人

这不是题材问题，是**深度只做在内容表层**。Wordle 能活，是因为每天一题、社交比分；《赵云与阿斗》能打榜，是因为「对上」之后单位活了，还有对局。我们两样都不抄，但必须有自己的第二层。

**一句话判断**

> 通知是皮。对上是动词。能让人留下的，是「这一局的话被我改成了别人改不出的样子」，以及「下一句会因为我刚才那对词而不一样」。

只加皮，产品会死在第 3 天。加第二层，3–6 分钟的 IAA 单局才站得住。

---

## 1. 永远不改的东西

这些是宪法。宏观设计只能往上长，不能改它们。

| 锁死 | 值 |
|---|---|
| 主体验 | 我对上了这两个字 |
| 核心动词 | 选两个有序字，组成一个词，改写场上那句话 |
| 失败 | 对不上（组错 / 超时），不是漏怪 |
| 场面 | ≤ 12 个字，认得出每一个 |
| 不做 | 塔防、二合升级、自走观战、转珠、战棋、词库抽卡、付费胜率 |
| 单局 | 3–6 分钟，进来就是纸面 |
| 广告 | 核心流程 ≤ 2 |
| 局外 | 首版没有第二条养成线 |

**和 code_1 的分工**：那边改人，这边改话。任何「三选一捡配件、看他们打」的提案，直接回 code_1，不要接到本品类。

## 2. 四层结构（真正能扩展的是后三层）

```
L0  动词（锁死）     点两个有序字 → 对上 / 反序 / 踩坑 / 对不上
L1  皮（会腻）       通知、群消息、邮件……题材皮肤
L2  语法（主深度）   这一局「怎样才算对上」
L3  后果（主留存）   我改过的词，改变后面的句子
L4  模式（主传播）   日更一句、话题、把改写发到聊天
```

L1 必须有，用来换皮和过审。  
**产品寿命看 L2 和 L3。** L4 是 IAA 自然量和社交的来源。

开发排期按这个优先级：**先把 L0 做爽 → 接上 L3 的最小后果 → 再加 L1 主题 → 最后开 L2 新语法和 L4 模式。**  
不要一上来做图鉴、做赛季、做 PVP。

---

## 3. L1 皮：主题，不是关卡列表

主题是一套词库 + 一套句子口气，不是「第 17 关」。

| 主题 | 玩家在改什么 | 为什么值得做 | 何时开 |
|---|---|---|---|
| **职场**（已有） | 通知、纪要、客户群 | 现代题材、审核稳、人人认得 | 首版唯一主题 |
| 过年回家 | 亲戚一言、红包、催婚 | 强季节、梗密度高 | 第一个节日周 |
| 相亲饭局 | 介绍、条件、微信 | 一句能转发 | 主题 2 |
| 游戏群 | 开黑、背锅、GG | 核心用户自嘲 | 主题 3 |
| 热搜标题 | 当天口气的假新闻标题 | 日更素材、直玩好拍 | L4 接上后再做 |

**一条主题的合格标准**

- 至少 24 句底库（够随机构成 3 个不重复的「一天」）
- 每句有且只有一个要改的词（`mark`）
- 每句 ≥ 2 条改写、1 条陷阱、改写可反序
- 改写后的新句本身也是一句能念出来的人话，不是「+12」
- 主题内口气统一：职场像通知，过年像亲戚，不要混

**内容工厂（以后写句都按这个填）**

```
source:   群通知
notice:   今晚全体加班
mark:     加班
goal:     改掉加班
rewrites: 取消 → 今晚全体取消
          摸鱼 → 今晚全体摸鱼
trap:     加班 → 今晚必须加班
tone:     损、短、能当梗
```

一旬合格的改写，必须能让没玩过的人听完就笑或点头。听完要解释的，重写。

题材轮换是保鲜，**不是深度**。同一主题写到 200 句，玩家仍可能觉得是同一款游戏。所以 L1 有配额：每个大版本只上一个新主题，先把旧主题的 L3 做完。

## 4. L3 后果：这一局为什么和上一局不一样（优先做）

这是切片之后的第一刀产品。没有它，8 句只是 8 道独立填空。

**规则（最小）**

玩家对上的词，作为「今天的案底」留下。后面的句子会点名这个词。

| 你上午对上 | 下午可能落到的句子 |
|---|---|
| 取消 | 谁把通知取消的，站出来 |
| 摸鱼 | 监控显示全员摸鱼 |
| 请假 | 你的假条被打回了 |
| 鸽了 | 对接群在等你的进度 |

解法仍然是组对，不是看动画。但玩家会感到：**我上午那对词，把下午的局面写死了。**  
这正是 00 里「本局独有」的落地，而且不靠随机抽卡。

**实现约束**

- 案底只在本局有效，隔天清空。不做养成。
- 一张「后果表」：`word → 后句模板`。没有的词不触发，走默认下一句。
- 后句仍然要满足「一眼能对」，不能变成阅读理解。
- 同一天最多触发 2 次后果，避免写成连续剧。

**验收**

打完一局问：「下午那句为什么是这句？」  
答得出「因为我上午组了××」即通过。答「下一关」即失败。

## 5. L2 语法：深度怎么往上加（第二刀）

动词永远是组对。变的是**怎样才算对上**。一次只开一种新语法，开之前旧语法必须已经好玩。

按这个顺序解锁，不要跳。

| 阶 | 语法 | 玩家新学的 | 风险 |
|---|---|---|---|
| 0 | 双字词 + 语序（已有） | 请假 ≠ 假请 | — |
| 1 | 后果句（§4） | 我的词会回来 | 后句太绕 |
| 2 | 一句两处 | 一张通知里两个红词，对上其中一个即可过，对上两个算「改干净」 | 变填空题海 |
| 3 | 对仗 | 上联已写死，组一对打下联；对上的是口气，不是同义词表 | 做成语文作业 |
| 4 | 谐音 | 「带薪」对「怠工」这类一眼能懂的谐音才算；偏僻谐音不做 | 地域梗、审核 |
| 5 | 三字词 | 先对两个，再接第三字（「对不起」）。场上仍 ≤ 12 字 | 变成长链合成，撞花花 |

**「改干净」不是星级关卡。** 对上一个就能进下一句；两个都对上，只多一句结算彩蛋。不要做成三星重打。

**修辞（如果要做局内成长，只准做成这个）**

一天中间可以出现一次「今天说话的方式」，只改判定，不改数值：

- 正序才算（默认）
- 反序也算，但改写变弱（句子只改一半）
- 谐音也算（仅当天）

这不是三选一捡装备。选项是**一句话的规则**，选完立刻用在下一句上，当天结束作废。不做图鉴、不做升级、不做稀有度。

若做出来像 code_1 的改装件，砍掉。

## 6. L4 模式：什么时候才开第二条玩法

主模式永远是「改完今天的句子」。其他模式是卫星，不是第二款游戏。

| 模式 | 做什么 | 为什么值得 | 前置 |
|---|---|---|---|
| **今天**（主） | 3–6 分钟，8–12 句，带后果 | 主体验 | 已有 |
| **今日一句** | 全服同一句，改完可转发「我把××改成了××」 | 日活、素材、社交 | 主模式留存稳住 |
| **话题周** | 一周一个热题（裁员、春节、开学） | Live Ops，不改代码 | L1 工厂跑通 |
| **对改**（慎） | 异步：你改完的句子变成对方的开局句 | 传播 | 今日一句先跑；**不做实时 PVP** |

今日一句的胜利条件仍然是「对上了」，不是排行榜伤害。排行如果要做，只排「改法有多损」的人工/投票，不做 DPS。

## 7. 一天怎么长（会话结构）

完整产品的一天，不是切片的 8 张独立卡。

```
进纸面（无菜单）
  → 上午 3 句（教 + 建立案底）
  → 中午 1 句（可选手里的修辞，可跳过）
  → 下午 3 句（至少 1 句吃案底）
  → 收工 1 句（今天的总句，点名你用得最多的那个词）
  → 结算：列出「本局靠哪些词」，以及「下午因××变成了××」
```

时长仍压在 3–6 分钟。句子变多靠每句更快（20–28 秒），不靠把单句做成谜。

**难度不靠更偏的词。** 难度来自：

1. 字池里同时放能赢的词和陷阱词（已有）
2. 案底把后句的解法拧一下（L3）
3. 偶发一句两处（L2）

不靠生僻字，不靠 12 个字以上，不靠倒计时压到 8 秒。

## 8. 加 / 慎 / 砍（宏观速查）

| 倾向 | 可以 | 为什么 |
|---|---|---|
| **加** | 案底后果、主题词库、今日一句、结算转发、修辞当天有效、一句两处 | 服务「对上了」或「本局独有」 |
| **慎加** | 对仗、谐音、三字词、对改、节日主题 | 容易变成作业、合成或第二款游戏 |
| **砍** | 图鉴收集当主循环、词稀有度、战力、棋盘、漏怪、二合升级、实时对战、章节地图、体力墙 | 忘了主语，或撞现有工程 |

**提案过滤器（写需求时填）**

1. 玩家完成它时，会不会说出一个具体的词？
2. 不做它，现有的「对上」会不会变弱？
3. 外人 10 秒看会不会说成塔防 / 合成 / 消消？
4. 它是不是在逼玩家肝或付费才能对上？

四个里有一个「否」，降权或砍。

---

## 9. 商业化在宏观里的位置

商业化是插座，不是玩法。细节见 00 §5。

| 阶段 | 做什么 | 不做什么 |
|---|---|---|
| 现在 | 资源入口带 `source`；埋点 `run_*` / `pair_try` / `notice_rewrite` | 不接支付 |
| 切片可玩之后 | 核心 2 点：续命或加时、结算双倍 | 不插屏 |
| 今日一句上线后 | 局外：看广告换一套纸面 / 次日主题预告 | 不卖必出词 |
| 有版号后 | 外观、纸面、字体 | 仍不卖胜率 |

IPU 仍看中位数 ≥ 6。今日一句是把曝光摊到「每天打开」，不要在主流程里加第三个广告点。

## 10. 内容与工程怎么拆（避免做成手工作坊）

| 层 | 谁改 | 形态 |
|---|---|---|
| 引擎 | 程序 | `PairEngine`：四类结果、案底、语法开关 |
| 句库 | 策划 / 文案 | `balance/themes/<theme>/*.ts`，一句一条，可单测 |
| 后果表 | 策划 | `word → 后句 id`，缺省走默认队列 |
| 语法 | 程序 + 一句策划说明 | 开关，默认关 |
| 主题皮 | 文案 + 极少美术（纸色、印章） | 不新做角色立绘 |

**一句的自动验收（CI 要钉）**

- `notice` 含 `mark`
- 每条 rewrite 的 `nextText` ≠ `notice`
- 每条 rewrite 可反序且反序不是 rewrite
- `pool` ≤ 12，且覆盖所有 pair 用到的字
- `nextText` 长度 ≤ 14 字（念得完）

文案比程序贵。程序不要给自己做「万能生成器」幻想；先把填表和验收做好，生成器以后再说。

## 11. 开发阶段（按这个做，不要横跳）

每阶段有退出条件。没达到就不要开下一阶段。

### P0  现在（切片）

**做完的**：一天 8 句、引导、先/后槽、四类结果、微信包。  
**还欠的**：外人能不靠你讲解打完第一句；结算能指回词。  
**退出**：5 个没玩过的人里，至少 4 个能说出「点两个字改通知」。

### P1  能当一款游戏（下一阶段，约 1–2 周）

- 案底后果（§4）
- 职场底库扩到 24 句，每天开局抽 8 句且上午固定教
- 广告 2 点接上（可先假按钮）
- 埋点按 01 节
- 输了能立刻再来，不回菜单

**退出**：同一人连打 3 局，能讲出「这局下午和上局不一样，因为我组了××」。中位数单局 3–6 分钟。

### P2  能活过一周

- 今日一句 + 转发文案（「我把今晚全体加班改成了今晚全体摸鱼」）
- 第二个主题只准备素材，先不上线
- 一句两处（可选，小流量验证）

**退出**：今日一句的次日打开不是 0；转发素材能看懂游戏。

### P3  能活过一个月

- 话题周（运营换表，不发版本）
- 至多一种新语法（对仗或修辞三选一，不能两种一起上）
- 纸面 / 字体外观预留

**退出**：31–90 天流水占比有机会碰到微信长线激励门槛；主体验没有被新语法带偏。

### 明确不做的阶段

- 不做「100 章推图」
- 不做开放世界改公文
- 不做文字 MMORPG
- 不做和《赵云与阿斗》对标的塔防赛季

## 12. 和切片代码的对应

| 设计层 | 现在的代码 | 下一步改哪里 |
|---|---|---|
| L0 动词 | `PairEngine` + 四类结果 | 少动。新语法用开关，不要改四类名字 |
| L1 职场 8 句 | `balance/slice.ts` | 拆成 `balance/themes/work/`，切片变成主题的一个 seed |
| L3 后果 | 无 | `RunState.record: string[]`，`balance/consequences.ts` |
| L2 语法 | 无 | `RunState.rule`，默认 `strictOrder` |
| L4 模式 | 无 | 后置。不要先做选模式页（撞十秒可懂） |
| 演出 | `PlayScene` | 后果触发时必须点名「因为你组了××」 |

## 13. 风险

| 风险 | 怎么表现 | 对策 |
|---|---|---|
| 填空疲劳 | 「又是两个字」 | 先上后果，不上第 9 句 |
| 语文作业 | 玩家去想成语词典 | 只用大众词；谐音、对仗后置 |
| 做成塔防 / 合成 | 外人第一眼认错 | 00 反目标，每版盲测 |
| 内容跟不上 | 一周写不动 24 句 | 主题少、句子短、验收自动化 |
| 抄爆款壳 | 守门、二合、站桩 | 提案直接对照 §1 |

---

## 14. 现在就锁死的决策

1. 下一阶段只做 **L3 案底后果 + 职场 24 句**，不做新主题、不做新模式、不做新语法。
2. 不把一天做成章节地图。
3. 不把词做成收集养成。
4. 实时 PVP 永久不做。
5. 有人提「加点战斗让它更像游戏」，回 00：战斗是 code_1 的活。

## 一、升级背景与旧版痛点

1. **箭矢细碎竖线发虚**：旧版 `wp_arrow_hunt`、`wp_bolt_yanqing` 等贴图含版画式半镂空竖线纹理（不透明像素仅 20.5%），缩至局内 70～80px 后在暖米色石板路上发灰、半透。
2. **保护色撞地面且无落地投影**：灰褐细木杆与石板路同色系，缺少粗深色外描边，且 `ShotKind.Arrow` 关闭了地面轻投影，视觉悬空发飘。
3. **写实细瘦比例与 Q 版角色脱节**：旧版长枪/飞刀采用 1:6 牙签细杆与细碎写实刻线，与已升级的 2 头身呆萌圆甲官兵及 Q 版好汉画风割裂。

## 二、呆萌软胶风四大铁律（与 `07` 号规范同源）

1. **暖深褐粗均匀外描边（`#2B2338`）**：
   - 全套武器统一使用连续饱满的 `#2B2338` 暖深褐紫粗轮廓线（不用死黑，也不用无描边过渡），确保在浅米黄石板地、草地、水滩上都像贴纸般刀刻清晰。
2. **Q 版圆润敦实比例（Chunky Soft-Vinyl Toy）**：
   - **箭矢/弩矢/飞叉**：箭头放大至全长 **40%～45%**，尖端带微圆倒角；箭杆加粗为短实圆木杆；尾羽做成圆鼓鼓的两片奶油白+高饱和亮色软羽（整体宽高比约 `1 : 2.2`）。
   - **长柄神兵（蛇矛/麒麟枪/钩镰/青龙刀/禅杖）**：采用 **1 : 2.6 ～ 1 : 3.0** 的敦实 Q 版长柄比例（大枪头占 42%～46% + 呆萌圆瑞兽吞口 + 圆绒球红缨 + 粗实圆杆），既一眼认出是长柄武器，又绝不细如牙签。
   - **重武/火器/法宝**：圆滚滚球体/厚块体，搭配胶囊形亮白高光点（Pill-shaped gloss dot）。
3. **严守「三不画」极简大色块原则**：
   - **不画裂口缺角与划痕**；
   - **不画细密铆钉、木纹杂线、细碎麻绳丝与复杂龙鳞**（瑞兽吞口简化为圆萌猫豹头/小青龙圆头，渔网简化为 3×3 粗绳大格）；
   - **不画半透明外发光雾**（武器本体 100% 实心不透明，流光气场统一交由 `BattleView` 的 `FxUber` 动态特效层叠加）。
4. **局内空间实体感**：
   - `BattleView` 为飞行箭矢恢复贴地轻椭圆暗影（`alpha ≈ 0.22`），与胸口高度飞行的箭体拉开立体离地层次。
